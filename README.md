# QQ 加群引导系统

单页架构的 QQ 群加群引导站点，用户输入卡密后查看官方群列表并一键跳转。后台提供基础配置、加群配置、卡密配置与统计功能。

- 运行环境：PHP 8.0+ / MySQL 5.6+（含 MariaDB 10.x）
- 技术栈：原生 PHP + PDO 预处理 + 原生 HTML/CSS/JS，无框架、无 Composer 依赖
- 字符集：utf8mb4；SQL 已规避窗口函数、JSON 函数、CTE 等 MySQL 5.6 不支持的语法

## 功能

前台（`index.php`，单页）

- 卡密验证门：未验证卡密不返回任何群数据，页面源码中也不含群链接
- 群列表：服务端实时探测加群链接，右侧显示 ✅ 可加入并附延迟 ms，或 ❌ 不可用
- 点击统计：已验证用户点击群时记录点击量
- 群跳转：优先使用后台配置的专属链接；未配置时按接口模板用群号自动生成加群链接（默认接入糖豆子「打开QQ群」接口）

后台（`admin/`，单页）

- 顶栏标题「加群后台」，移动端汉堡菜单 + 侧边抽屉
- ① 基础配置：站点名称、副标题、公告、主题色、页脚、验证文案、是否显示群号、修改管理员密码
- ② 加群配置：群的新增 / 编辑 / 排序 / 启用停用 / 删除，群号与自定义跳转链接；支持单群测试与全部测试，并展示最近探测结果
- ③ 卡密配置：自定义前缀与时长（天/小时）批量生成、卡密列表筛选与搜索、启用禁用、删除、复制全部；支持批量启用/禁用/删除/续期、CSV 导出、自定义卡密导入、绑定状态查看与解绑、防分享绑定设置
- ④ 统计功能：今日与累计 PV / UV / 激活 / 点击，近 7 / 30 天趋势图，群点击排行，卡密概况

## 安装

1. 将代码上传到支持 PHP 8.0+ 的 Web 目录。
2. 浏览器访问 `/install/`，按向导完成环境检测、数据库信息与管理员账号设置。
3. 安装向导会自动创建数据表、写入 `config.php`、生成 `install/install.lock`。
4. 安装完成后建议删除或重命名 `install` 目录。

本地快速预览：

```bash
# 启动内置服务器（端口可自定义）
php -S 0.0.0.0:8080
```

## 加群链接生成

后台「加群配置」可设置跳转接口模板，`{group_no}` 会被替换为群号。默认模板：

```
https://api.tangdouz.com/qqtzq.php?qh={group_no}
```

接口来源：糖豆子 API「打开QQ群」，访问该地址即跳转打开对应 QQ 群。优先级为：群的专属跳转链接 > 接口模板自动生成。若模板留空且群未配置链接，前台会退化为复制群号提示。

## 群状态实时探测

前台群列表的 ✅/❌ 由服务端实时探测加群链接得到，逻辑如下：

- 探测方式：先发 HEAD 请求，遇到 403/405/501 时用 GET 重试；不跟随跳转，2xx/3xx 视为可访问。
- 返回结果：可访问显示 `✅ 可加入 · Nms`，不可访问显示 `❌ 不可用`，N 为响应耗时（毫秒）。
- 并发执行：使用 `curl_multi` 一次性并发探测所有群，避免串行等待。
- 结果缓存：写入 `qc_link_status` 表，缓存时长由后台「加群配置」的「状态缓存时长」控制（默认 300 秒，范围 30-3600），避免频繁请求被第三方接口限流。
- 后台可点「全部测试」或单个群「测试」强制刷新（忽略缓存）。
- 后台把群设为「停用」时，前台直接显示 ❌ 且不参与探测。

## 卡密规则

- 前缀与随机后缀长度均可配置，随机字符集排除易混淆字符（0/O/1/I）
- 时长支持天或小时，生成时统一换算为小时存储
- 激活时起算有效期；同一卡密在有效期内可重复登录
- 支持导入自定义卡密（每行一个，4-64 位字母/数字/横线/下划线，自动去重与校验）
- 批量操作：启用、禁用、删除、续期（续期从当前到期时间顺延，已过期则从当前时间顺延）
- 导出 CSV（含卡密、时长、状态、激活/到期时间、激活 IP、创建时间）
- 每次生成或导入都会记录批次号，可随时点「复制最新卡密」复制最近一次生成的整批卡密
- 连续验证失败 5 次锁定 10 分钟；后台登录同样限速

### 防分享绑定

后台「卡密配置」可选择绑定模式：

- 不绑定：同一卡密可在多设备使用
- 绑定首次激活 IP：其他 IP 登录会被拒绝
- 绑定首次激活设备：通过设备 Cookie 识别，其他设备登录会被拒绝

绑定模式下，管理员可在卡密列表对已绑定卡密点「解绑」，解绑后下次登录会重新绑定。绑定 IP 对移动网络用户可能因 IP 变化误拦，请按需选择。

## 界面与可访问性

- 统一设计尺度：颜色、圆角、阴影、层级均通过 CSS 变量管理；后台主题色跟随「基础配置」的站点主题色。
- 图标使用内联 SVG，保证跨平台一致与可配色。
- 后台顶栏显示当前模块名，移动端汉堡菜单抽屉式导航。
- 卡密表格在窄屏自动切换为堆叠卡片，避免横向滚动。
- 弹层支持 ESC 关闭、打开时锁定背景滚动并自动聚焦、关闭后焦点归位。
- 表单控件有可见标签与焦点环，状态不只依赖颜色（同时有文字/图标）。
- 全站支持 `prefers-reduced-motion`，动画时长控制在 150-300ms。
- 前台群列表可键盘操作（Tab 聚焦、回车/空格加入）。

## 安全说明

- 全部数据库操作使用 PDO 预处理，防止 SQL 注入
- 后台写操作要求登录态并校验 CSRF token；导出接口额外校验一次性 token
- 页面输出统一 HTML 转义，接口统一 JSON 编码
- 未验证卡密不向前端输出任何群信息
- 卡密验证与后台登录按 IP 限速（分别 15 次 / 10 次失败锁定 10 分钟），记录写入 `qc_rate_limits`
- 仅在直连来源为内网/本机（可信代理）时才采信 `X-Forwarded-For`，避免客户端伪造 IP
- 修改管理员密码会递增 `token_version`，使所有已登录会话立即失效
- 卡密激活使用条件更新（`WHERE used = 0`）保证并发下只激活一次
- 安装生成的 `config.php` 权限为 640
- 请为后台账号设置强密码，并在生产环境启用 HTTPS
